KERNBEGRIFF

Vibe Coding

Vibe Coding bedeutet: Du beschreibst einer KI auf natürliche Sprache, was du bauen willst — und sie schreibt den Code. Du musst kein Profi sein. Du gibst den Vibe (Gefühl, Richtung, Idee) vor, die KI übernimmt die technische Umsetzung. Das Ziel ist nicht perfekter Code — sondern schnell etwas zum Laufen bringen.

🎬 Analogie: Du bist der Regisseur. Die KI ist dein Programmierer-Team.
PROMPT-KONZEPTE
💬
Begriff

Prompt

Die Texteingabe, die du einer KI gibst. Je klarer und strukturierter der Prompt, desto besser das Ergebnis. Ein guter Prompt nennt: Was soll gemacht werden, wie soll es aussehen, was soll nicht passieren.

„Bau eine Webseite mit einem Zähler, der hochzählt, wenn ich klicke."
🧩
Begriff

Prompt Framework

Eine wiederverwendbare Vorlage für Prompts. Statt jedes Mal neu zu überlegen, füllt man einfach die Bausteine aus — und bekommt einen fertigen, gut strukturierten Prompt. Genau das ist der linke Tab.

Felder ausfüllen → fertiger Prompt. Einmal lernen, immer nutzen.
🎨
Begriff

Vibe

Der ästhetische und emotionale Charakter eines Projekts — nicht die Technik, sondern das Gefühl. Soll es clean und minimalistisch wirken? Dunkel und modern? Bunt und verspielt? Der Vibe steuert Design-Entscheidungen.

„Dunkel, modern, wie ein Hacker-Terminal."
⚙️
Begriff

Stack / Technologie

Die Kombination aus Programmiersprachen und Tools für ein Projekt. Für Einsteiger reicht oft: HTML, CSS und JavaScript. Für größere Projekte kommen Frameworks wie React oder Backend-Sprachen wie Python dazu.

„HTML + CSS + JavaScript, läuft im Browser, kein Server nötig."
🏗️
Begriff

MVP

Minimum Viable Product — die kleinstmögliche Version, die funktioniert. Kein Schnickschnack, keine Extras, nur das Wesentliche. Im Vibe Coding: erst den MVP bauen, dann schrittweise erweitern.

„Nur das Nötigste — ohne Login, ohne Datenbank."
🔒
Begriff

Einschränkungen

Bedingungen, die der Code erfüllen muss — oder Dinge, die explizit vermieden werden sollen. KIs bauen sonst gerne komplexe Lösungen. Klare Grenzen halten das Ergebnis schlank und tatsächlich nutzbar.

„Kein Backend, keine npm-Pakete, nur eine einzige HTML-Datei."
TECHNISCHE BEGRIFFE
🌐
Begriff

HTML / CSS / JS

HTML = Struktur (was ist auf der Seite). CSS = Aussehen (wie es aussieht). JavaScript (JS) = Verhalten (was bei Klick passiert). Diese drei bilden das Fundament jeder Webseite.

HTML: Knopf. CSS: Knopf ist blau. JS: Klick macht was.
⚛️
Begriff

Framework (React, Vue …)

Ein vorgefertigtes Baukasten-System. React und Vue helfen dabei, komplexe, interaktive Webseiten mit wiederverwendbaren Komponenten zu bauen. Für einfache Einstiegsprojekte oft nicht nötig.

React: gut für Apps mit vielen interaktiven Teilen.
🖥️
Begriff

Backend vs. Frontend

Frontend = alles, was der Nutzer im Browser sieht. Backend = der Server im Hintergrund (Datenbank, Login-Logik). Viele Vibe-Coding-Projekte brauchen gar kein Backend.

Frontend: Webseite. Backend: Server, der Daten speichert.
📦
Begriff

Dependencies / npm

Externe Code-Bibliotheken, die man einbindet. npm ist das Tool zum Installieren. Mehr Dependencies = mehr Komplexität. Für Einsteiger: lieber ohne starten, weniger kann mehr sein.

„Kein npm nötig — alles in einer HTML-Datei."
💾
Begriff

Datenbank / SQLite

Ein Ort, wo Daten dauerhaft gespeichert werden. SQLite ist eine leichtgewichtige Datenbank für lokale Tools. Viele einfache Projekte kommen ohne aus — Daten leben dann nur im Browser-Speicher.

Ohne Datenbank: Daten weg nach Seiten-Reload.
♿
Begriff

a11y / Barrierefreiheit

a11y steht für „Accessibility" (11 Buchstaben zwischen A und Y). Bedeutet: die App soll auch mit Screenreadern, per Tastatur und bei eingeschränktem Sehvermögen gut nutzbar sein.

KI nach „barrierefreiem Code" fragen — sie kennt die Standards.
